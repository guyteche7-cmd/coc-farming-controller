BUILDER BASE 2.0 AUTOMATION MODULE - ARCHITECTURAL PLAN (plan.txt)
================================================================================

1. MODULE OBJECTIVE & INDEPENDENCE
--------------------------------------------------------------------------------
- Create a fully self-contained directory `builderBase/` inside the project.
- No modifications to existing main village code that would cause breaking changes.
- If `builderBase/` is deleted, the main village farming controller (`run_coc_bot.bat`)
  continues to function 100% properly without errors.
- A dedicated standalone launcher `run_bb_bot.bat` will start the Builder Base bot.
- Shared infrastructure utilities (e.g. screen capture, win32 input adapter, window calibrator)
  can be imported cleanly from `src.` with fallback guards.

2. BUILDER BASE 2.0 GAMEPLAY SPECIFICATIONS
--------------------------------------------------------------------------------
A. Flow & State Transitions:
   1. BB_HOME (Builder Base Home Village)
      - Detect bottom-left "Attack!" crossed axes button.
      - Click "Attack!" button at norm (0.055, 0.885).
   2. BB_START_ATTACK_MODAL (Popup: "Start Attack")
      - Detect modal titled "Start Attack" with troop lineup & "Iron League III".
      - Click green "Find Now!" button at norm (0.740, 0.611).
   3. BB_MATCHMAKING ("Searching for opponents...")
      - Detect clouds/searching screen with spinning magnifying glass.
      - Wait until opponent base is loaded.
   4. BB_STAGE1_BATTLE (Stage 1 Opponent Base)
      - 6 Troop Slots (1-6) + 1 Hero Slot (Slot 0, far left).
      - Deploy Hero at designated spot (black dot on top-right perimeter: norm 0.776, 0.102).
      - Deploy Troop Slots 1 -> 6 sequentially at the deployment spot.
      - Trigger Hero Ability (Battle Machine Electric Hammer) whenever charged (or after deployment).
   5. BB_STAGE_TRANSITION (Stage 1 Complete -> Stage 2 Auto-Advance)
      - When Stage 1 base is destroyed or army clears, game automatically transitions to Stage 2.
   6. BB_STAGE2_BATTLE (Stage 2 Opponent Base)
      - 8 Troop Slots (1-6 surviving + 7-8 Reinforcements).
      - Deploy Reinforcements (Slots 7 and 8) + any remaining units at deployment spot.
      - Trigger Hero Ability when active.
   7. BB_BATTLE_EXIT / SURRENDER / END BATTLE
      - Condition: all buildings destroyed (100%/200%) OR all troops expended OR user timer.
      - If < 50% damage: Click "Surrender" at norm (0.072, 0.644) -> Click "Okay" at norm (0.594, 0.593).
      - If >= 50% damage / 1+ Star: Click "End Battle" at norm (0.072, 0.644) -> Click "Okay" at norm (0.594, 0.593).
   8. BB_RESULT_SCREEN (Battle Rewards & Stars)
      - Detect result screen with stars, damage %, and "Return Home" button.
      - Click "Return Home" button at norm (0.500, 0.783).
      - Return to BB_HOME and repeat according to attack count settings.
